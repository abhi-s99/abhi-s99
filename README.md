## 🚀 Featured Projects

| Project | What it does | Stack |
|---|---|---|
| **LegalLens** | RAG legal-aid assistant over 50+ legal PDFs (∼4,000 pages) with page-level citations. Hybrid vector + full-text retrieval (Reciprocal Rank Fusion) raised Recall@5 from **0.62 to 0.84**; median retrieval latency **under 80 ms**. | Python, FastAPI, React, pgvector, OpenAI API, AWS |
| **Privacy Breach Lab** | Platform to assess disclosure risk from five privacy attacks (linkage, inference, membership inference, deanonymization, reconnaissance), with masking, suppression and generalization, validated against k-anonymity, l-diversity and t-closeness. | Python, Flask, FastAPI, React, MongoDB |
| **Campus Mart** | Campus marketplace with bidding, shipped end-to-end in a 3-week sprint: 8 REST endpoints, RBAC, server-side bid validation, 50+ live listings. | Node.js, Express, MongoDB, JavaScript |
| **ClearGate** | Privacy gate between business documents and AI models: extracts text from PDFs (including scans), Word and PowerPoint, detects and redacts PII, and independently verifies the result. Built for the Optiv Consulting case study. | Python, TypeScript, React, Docker |
| [**Ariadne**](https://github.com/abhi-s99/ariadne-agentic-code-search) | Agentic code retrieval on pure CPU (<35M params) for the CoIR `apps` benchmark. Built with Team Aftermath for the Samsung PRISM GenAI Hackathon; I built the React demo and browser API. | Python, JavaScript, Docker |
| [**HTTP/3 vs HTTP/2 Testbed**](https://github.com/abhi-s99/http3-vs-http2-quic-testbed) | Rootless network-namespace testbed comparing HTTP/2 (TCP) and HTTP/3 (QUIC) under emulated loss and latency with `tc netem`, nginx and aioquic. | Python, Shell, Linux networking |
